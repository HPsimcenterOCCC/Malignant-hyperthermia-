# MH Crisis Simulator

A live monitor malignant hyperthermia scenario for ANES 1123 (Oklahoma City Community College, Anesthesia Technology program). The student plays the anesthesia technologist, answers the team and earns points for each finding and action.

## Hosting with GitHub Pages
1. Open **Settings > Pages**.
2. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Share the published link with students.
